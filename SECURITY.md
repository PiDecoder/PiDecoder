# Security Policy

## Supported versions

Security fixes are currently applied to the latest release candidate and, after launch, the latest stable release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose credentials, camera streams or remote access.

Contact the maintainers privately through GitHub organization contact methods.

Please include:

- affected version
- environment
- impact
- reproduction steps
- suggested mitigation, if known

## Sensitive information

Never publish:

- RTSP usernames or passwords
- ONVIF credentials
- private camera URLs
- private IP addressing plans
- camera serial numbers
- exported logs containing credentials
- authentication files
