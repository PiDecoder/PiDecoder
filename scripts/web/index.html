Réseau

  
Nom d'hôte, adresse IP, NTP et fuseau horaire du Raspberry Pi. Par sécurité, un changement de nom d'hôte ou d'adresse IP est automatiquement annulé s'il n'est pas confirmé dans les 45 secondes qui suivent — pour ne jamais perdre l'accès au Pi à distance à cause d'une erreur de frappe.

Mot de passe administrateur
Le mot de passe actuel est requis. Le nouveau mot de passe doit être saisi deux fois à l’identique.
Accès à l'interface Web
Protocoles, ports et certificat de l'interface d'administration : HTTP, HTTPS et leurs numéros de port.
Certificat HTTPS
Génère ou importe le certificat de l'interface Web, et active ou désactive HTTPS.
Ceci redémarre l'interface Web et recharge la page dans quelques secondes.
Importer un certificat
L'import n'est possible qu'en HTTPS — active d'abord HTTPS ci-dessus.
Accès HTTP
Active ou désactive l'accès à l'interface Web en HTTP simple (non chiffré), sur son propre port. Peut être coupé indépendamment de HTTPS ci-dessus — mais jamais les deux à la fois.
Ceci redémarre l'interface Web (jusqu'à environ 30 secondes). Si tu es actuellement connecté en HTTP, la page basculera automatiquement vers HTTPS.
Ports de l'administration Web
Change les numéros de port HTTP/HTTPS sans réinstaller. Redémarre aussi le moteur vidéo pour que l'écran du player affiche tout de suite les nouveaux ports (coupure de quelques secondes de l'affichage).
Accès SSH
Active l'accès SSH pour te connecter à distance en ligne de commande (dépannage, mise à jour manuelle). Désactivé par défaut sur l'image PiDecoder.
⚠️ Aucun changement de mot de passe SSH n'a été fait depuis cette interface. S'il n'a pas été changé autrement, c'est probablement encore celui par défaut de l'image — à changer avant d'activer SSH sur un réseau qui n'est pas de confiance.
Mot de passe SSH
Change le mot de passe du compte Linux utilisé pour se connecter en SSH (le même que la session graphique). Le mot de passe demandé ci-dessous est ton mot de passe administrateur Web actuel — pas le mot de passe SSH — il sert seulement à confirmer que c'est bien toi.

Importer

Ajouter manuellement par IPv4
